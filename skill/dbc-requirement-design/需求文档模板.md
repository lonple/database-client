# 需求文档模板

复制本结构，另存为 `doc/设计/需求/NN-标题.md`。删掉不适用的小节，不要留空标题。专项需求在文首链到平台总需求 `01-需求设计.md`，并声明是否改变既有约束。

章节顺序取自 `02-智能问数需求分析.md` 与 `03-智能问数测评需求分析.md`：先问题与一句话路径，再信息架构与范围，然后场景、功能、拍板、验收。

```markdown
# ［名称］需求分析

| 项 | 内容 |
|---|---|
| 版本 | v0.1 |
| 日期 | YYYY-MM-DD |
| 工程 | `database-client`（DBC） |
| 范围 | 本篇覆盖的能力（一句） |
| 状态 | 方案分析 / 方案拍板 |
| 上游 | 平台需求或上一篇专项需求 |
| 下游 | 架构概要、详细设计（写完后回填链接） |
| UI | `doc/ui/` 下本功能各页 |
| 平台硬边界 | 目标库只经 `dbc-sqlwork`；浏览器不直连目标库 |

> 与上一篇的关系：本篇改变 / 不改变其哪些约束。

---
```
