---

## 1. 设计目标

- 工程绑定工作连接（临时表 / 结果 / 重跑）。
- Chat 生成、用户执行；会话日志；结果弹窗。
- **大模型与 Agent 运行可观测**：调用、图节点、Tool、与 Gateway TraceId 关联；云禁样本进 Trace。
- 目标库只经 `dbc-sqlwork`。

---

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 问数服务 | `dbc-askdata`（Python · 根包 **`dbc_askdata`**） | LangGraph ± Deep Agents；HITL；包规范见模块化 §2.4 |
| 工作流执行 | WorkflowRunner → sqlwork | 可停止；SSE |
| 可观测 | 结构化日志 + PG 监控表 + Prometheus 指标；MDC/`traceId` 贯通 | 对齐总架构可观测缺口 |
| 审计 | 业务/执行关键事件对接或对齐 `dbc-audit` | 与 LLM 监控分流：审计偏合规留存，监控偏性能与排障 |
| 平台库 | **PostgreSQL**（与平台共库）；**独立 schema `askdata`**（`CREATE SCHEMA askdata`） | 工程、工作流、run、llm_span 等元数据；**不是**工作连接上的临时表/结果表 |

端口建议：`8009`。

---

## 3. 逻辑架构

```text
dbc-front
  → gateway（注入 TraceId）→ dbc-askdata
        ├─ ToolRegistry + ToolGateway   # 仅已声明 Tool；禁止模型直调 meta/execute
        ├─ LangGraph / Deep Agents      # 只绑定注册表 Tool
        ├─ WorkflowRunner               # 用户执行（服务端调 sqlwork）
        ├─ LlmObservability / Metrics
        └─ SqlworkClient → dbc-sqlwork  # 仅 Handler / Runner 可调用
```

| 模块 | 职责 |
|---|---|
| ToolRegistry | 声明 Tool 名、入参 schema、注册条件（如 residency） |
| ToolGateway | 白名单分发；拒未知 tool；参数校验；写 span |
| LangGraph / Deep Agents | 只 tool_call 已声明工具；**看不到** sqlwork API |
| SqlworkClient | 供 Handler/Runner 内呼；**不**暴露给模型 |
| LlmObservability | LLM/图/Tool span |
| WorkflowRunner | 用户点执行后的节点调度 |

---

## 4. 监控与用户日志的边界

| 通道 | 受众 | 内容 |
|---|---|---|
| 会话 / 画布下侧日志 | 终端用户 | 业务过程、节点成功失败原因 |
| LLM 运行监控 | 运维 / 审计员 | **Grafana** + **审计中心「智能问数监控」**；业务用户不可见 |
| dbc-audit | 合规 | 谁在何时对何工程做了何操作 |

---

## 5. 安全边界（监控相关）

| 面 | 策略 |
|---|---|
| Tool 面 | 模型只能调注册表 Tool；禁止通用 execute/meta HTTP Tool |
| residency=cloud | Trace/监控载荷剔除 sample 正文与行级明细 |
| Prompt | 监控可存摘要/哈希/长度；全量 Prompt 默认关闭或仅 local |
| 失败策略 | 埋点失败只打 warn（带栈），不阻断生成/执行 |
| 第三方 | 不默认对接外传全量对话的 SaaS；若后置须评审 |

---

## 6. 主链路（含监控）

```text
请求带 TraceId → 生成/执行各阶段写 span
  → 指标递增 →（可选）审计 ingest
  → 用户侧仍只看会话日志与结果弹窗
```

## 7. 测评扩展（概要）

选空间后并列 **问数工作台** 与 **测评空间**。测评域（工程 / 用例 / 任务 / EvalRunner）复用生成图与 WorkflowRunner，增加自动保存执行、按 `case_key` 的 HITL 策略与结果比对。详见 [03-智能问数测评架构概要.md](./03-智能问数测评架构概要.md)。

---

## 8. 小结

工程绑定工作连接落数；平台元数据在 **PostgreSQL schema `askdata`**；LLM/Agent 可监控；sqlwork 碰库；测评为编排与评分层。
