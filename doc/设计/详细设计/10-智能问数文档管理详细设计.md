## 1. 定位与边界

**做：** 壳层菜单「文档管理」；上传 docx/pdf/xlsx/html 与 png/jpg/jpeg/bmp/tif/tiff/webp；Docling 两条管线转 Markdown；列表详情、改名、改正文、替换、软删（二次确认）；导入知识库草稿。

**不做：** 与需求 Out of Scope 同文（宏文件、旧版 Office、扫描 PDF 当图片识别、流程图结构、自动发布、碰库、新服务）。

## 2. 工程与包

| 维度 | 约定 |
|---|---|
| 目录 / Nacos / 网关前缀 | `dbc-askdata` / `/dbc-askdata/**`（StripPrefix=1） |
| 包名 | `dbc_askdata.documents` |

依赖：`docling` 为可选 extra `document`。本机已有 PyTorch 时只装 docling。未安装时转换接口 503。

## 3. 领域模型

表 `askdata.ask_document`（平台库，不是工作连接上的表）：

| 列 | 说明 |
|---|---|
| id | 主键 |
| owner_user_id | 创建人；列表只查此人 |
| name | 展示名 |
| source_format | docx/pdf/xlsx/html/png/… |
| source_filename | 原始文件名 |
| source_relpath | 相对 `DOCUMENTS_DIR` 的原件路径 |
| convert_status | QUEUED / RUNNING / SUCCESS / FAILED |
| convert_error | 失败原因 |
| pipeline | DOCUMENT / IMAGE |
| markdown | 转换或人工修订后的正文 |
| markdown_from_convert | 最近一次自动转换正文，用于判断偏离 |
| markdown_edited | 人工改过 |
| knowledge_document_id | 最近一次导入的 memory 文档 id，可空 |
| deleted | 软删 |
| created_at / updated_at | |

抽出图片：`{DOCUMENTS_DIR}/{owner}/{id}/assets/`。Markdown 内引用 `/dbc-askdata/api/documents/{id}/assets/{file}`（经网关鉴权）。

## 4. 行为设计

**校验：** 扩展名白名单；文件头魔数一致；拒绝 MZ（exe）、docm/xlsm；html 不跟随外链。xlsx 用 zip 内工作表数 >20 则失败。

**管线：** 见需求 §7.3。文档管线 `do_ocr=False`；图片管线 RapidOCR + 表格。阻塞调用放线程池，超时 180s。

**空结果：** 文档/PDF 几乎无文本则 FAILED（扫描件）。图片既无字也无表则 FAILED。

**替换：** `markdown_edited=true` 时 API 须 `confirmOverwrite=true`。

**删除：** 软删；磁盘文件可同期删除；不删知识库文档。

**导入：** 调现有创建知识逻辑，`publish=false`，`body=当前 markdown`。失败不改文档行。

**启动补偿：** `QUEUED`/`RUNNING` 改为 FAILED，原因「服务重启，请重试」，打日志带栈若有异常。

**审计：** `document.upload|replace|delete|import_knowledge`。

## 5. API

权限一律 `askdata.use`。仅 owner 可操作。

| 方法 | 路径 | 原型操作 |
|---|---|---|
| GET | `/api/documents` | 列表筛选 |
| POST | `/api/documents` multipart | 上传 |
| GET | `/api/documents/{id}` | 进详情 |
| PATCH | `/api/documents/{id}` | 改名 / 改正文 |
| POST | `/api/documents/{id}/replace` | 替换源文件 |
| POST | `/api/documents/{id}/retry` | 失败重试 |
| DELETE | `/api/documents/{id}` | 删除确认后 |
| GET | `/api/documents/{id}/source` | 下载原件 |
| GET | `/api/documents/{id}/assets/{name}` | 预览抽出图 |
| POST | `/api/documents/{id}/import-knowledge` | 导入草稿 |

列表轮询或详情轮询直到 SUCCESS/FAILED。

## 6. 前端

路由见 [06](./06-前端与界面设计.md) §9.1。壳层菜单增加「文档管理」。空态、删除二次确认、导入弹窗字段与知识创建一致（分类、名称、简介；元数据再选连接），**导入不发布**。

## 7. 风险

| 风险 | 表现 | 处理 |
|---|---|---|
| 未装 docling | 上传后失败 | 503/FAILED 文案写明安装 `pip install docling` |
| 转换超时/OOM | 停在转换中 | 超时 FAILED；启动清悬挂 |
| 单机目录 | 换机文件丢失 | 架构概要 §6；配置目录纳入备份 |
| HTML XSS | 上传 HTML 当页面 | 只转 Markdown；不把源 HTML 插入 DOM |
| CUDA/CPU 混装 | 本机正常、镜像无 torch | 本机用已有 torch；镜像不强制本期打入 |
