## 1. 定位与边界

**做：** 测评工程/模板引用/统一用例/任务跑批；测评模式自动保存并执行；按 `case_key` HITL 补全或不补全；期望 SQL 现场执行与结果比对；汇总指标。

**不做：** 模板发布流水线；多模型对比台；把金标结果集整表持久化为唯一真相（现场执行才是金标）。

相对 [08](./08-智能问数详细设计.md)：人工问数仍「生成后用户确认保存/执行」；**仅测评编排路径**允许无人自动跑流。

## 2. 领域模型（平台库 `askdata`）

### 2.1 表一览

| 实体 | 表 | 要点 |
|---|---|---|
| 测评模板 | `askdata.eval_template` | code、name、version、remark；内置种子 |
| 测评工程 | `askdata.eval_project` | workspace_id、name、remark、**template_id（引用）**、source_*、work_*、owner |
| 用例 | `askdata.eval_case` | **统一表**；scope=`TEMPLATE`\|`PROJECT_CUSTOM`；`case_key` 唯一 |
| 任务 | `askdata.eval_task` | project_id、status、指标 JSON、起止时间、创建人 |
| 任务用例快照 | `askdata.eval_task_case` | 创建任务时拷贝题面/期望 SQL/验证/HITL；跑批读写状态与比对摘要 |

### 2.2 `eval_case` 关键列

| 列 | 说明 |
|---|---|
| `case_key` | 全局唯一，如 `TPL_GOV_HITL_001` |
| `scope` | `TEMPLATE` / `PROJECT_CUSTOM` |
| `template_id` | 模板用例必填；自定义可空 |
| `project_id` | 自定义必填；模板用例空 |
| `category` | `SINGLE_FILTER` / `MULTI_JOIN_FILTER` / `SINGLE_AGG` / `MULTI_JOIN_AGG` / `COMPLEX_GOVERN` |
| `govern_subtype` | 仅治理类：`BOARD` \| `HITL_SUPPLEMENT` \| `HITL_NO_SUPPLEMENT` |
| `question` | 自然语言问题 |
| `expect_sql` | 期望 SQL（金标执行用；不补全类可空或仅作出题参考） |
| `compare_mode` | `key_set` \| `order_by` \| `scalar` \| `empty_or_refuse` |
| `compare_spec_json` | 键列、排序列、容差、参与比对列等 |
| `hitl_replies_json` | 字符串数组；仅 `HITL_SUPPLEMENT` |
| `tags_json` / `difficulty` / `enabled` | 辅助 |

**引用语义：** 工程用例列表 = 模板下 `TEMPLATE` 用例 ∪ 本工程 `PROJECT_CUSTOM`。删除工程不删模板用例；删除自定义仅删本工程行。

### 2.3 `eval_task_case` 快照与结果

| 列 | 说明 |
|---|---|
| 快照题面 | question、expect_sql、compare_*、govern_subtype、hitl_replies |
| `status` | 见架构状态机 |
| `ask_sql` / `ask_error` | 问数侧产物 |
| `hitl_rounds` | 实际补全轮次 |
| `compare_score` | 0～1 |
| `compare_detail_json` | 差异摘要（截断） |
| `expect_row_count` / `ask_row_count` | |
| `trace_id` / `workflow_id` / `run_id` / `session_id` | 关联问数执行、影子会话；任务详情可打开画布复看日志并再次执行 |

任务级指标可冗余在 `eval_task.metrics_json`，详情以明细聚合为准。

### 4.1 测评执行内核（内部，亦可对内暴露）

`CaseExecutor` 伪流程：

```text
1. chat_generate(question, eval_mode=true, project_bindings)
2. if needs_hitl:
     if subtype == HITL_SUPPLEMENT and replies left:
        resolve_hitl(next reply); goto 1
     if subtype == HITL_NO_SUPPLEMENT:
        finalize as refuse path → compare empty_or_refuse
     if subtype == BOARD:
        treat unexpected hitl as ASK_FAILED or continue policy（默认失败）
3. auto_save_workflow(draft)
4. run = workflow_runner.execute(workflow_id)
5. load ask result set
6. if compare_mode != empty_or_refuse:
     expect = execute_expect_sql(expect_sql)
     score = comparer(expect, ask, compare_spec)
7. persist eval_task_case
```

生成路径改造要点（`generate` / routes）：

- 增加 `eval_mode`：保存确认短路径；HITL 回调可被 EvalRunner 同步驱动。
- 会话可建「测评影子 session」（按 task_case 隔离），避免污染人工 Chat。

## 5. 比对详细规则

### 5.1 公共规范化

- 列名：trim + lower。
- 数值：`Decimal`，容差默认 `0.01`（用例可覆盖）。
- NULL：两边皆 NULL 相等。
- 时间：统一 UTC/连接会话时区策略与 sqlwork 返回一致。
- 截断：若 ask `truncated=true`，不得判 `PASSED`（可 `PARTIAL` 或 `FAILED_COMPARE`，模板默认后者）。

### 5.2 模式

| mode | 算法 |
|---|---|
| `empty_or_refuse` | **通过**：拒答或无业务结果；**失败**：执行成功且行数>0（误出数） |
| 其它（`scalar` / `order_by` / `key_set` 等） | **统一值比对**（见下），不再做字段映射 / 维度补全 |

**统一值比对（无字段映射）：**

1. **双方都只有一列**：不看列名，按值多重集比对（多余行惩罚见下）。
2. **多列**：
   - 必须列取自用例 `compare_spec.requiredColumns`（兼容 `columns`）；期望或问数缺列 → 状态 `MISSING_REQUIRED`；
   - 仅一行：直接比必须列；
   - 多行：在必须列中选排序列——有完全唯一列则用该列，否则取重复率最低的两列；按排序键分组后对必须列做多重集比对。
3. **计分**：`matched / expect_n`；若问数行数更多，则 `matched' = max(0, matched - (ask_n - expect_n))`。`score=1` 且行数相等 → `PASSED`；`≥0.8` → `PARTIAL_GE_80`。
4. 截断：`ask truncated=true` → `FAILED_COMPARE`。

≥80%：`compare_score >= 0.8` 且未 `PASSED` 时计入 `partial_ge_80`。

### 5.3 期望 SQL 执行

- 仅 SELECT（方言侧再校验）。
- sqlwork 返回为批结果（`statements[]`），测评侧必须 **归一化** 为首条成功语句的 `{columns, rows, rowCount}` 再比对 / 计 `expect_row_count`。
- `run_row_limit` 与问数一致或可配置更高上限（出题人注意 LIMIT）。
- 超时单独配置 `eval.expect_sql_timeout_ms`。

## 6. 指标汇总

```json
{
  "total": 100,
  "passed": 75,
  "passRate": 75.0,
  "askFailed": 5,
  "hasResult": 80,
  "exactPass": 60,
  "partialGe80": 10,
  "hitlSupplementPass": 18,
  "refuseOk": 15,
  "refuseBadLeak": 2,
  "boardPass": 40,
  "byCategory": [
    {
      "category": "SINGLE_FILTER",
      "total": 20,
      "passed": 18,
      "exactPass": 16,
      "refuseOk": 2,
      "askFailed": 1,
      "passRate": 90.0
    }
  ]
}
```

`passed` / `passRate`：`PASSED` + `REFUSED_OK` 占该类（或全任务）用例数。任务详情按分类展示通过率；分类取 `eval_task_case.category` 快照（创建任务时从用例拷贝）。详情页聚合以当前明细为准，跑批中亦随明细刷新。

任务详情 UI 展示总分与分类通过率；导出本期可不做。

## 10. 平台表 DDL 草案（schema `askdata`）

> 迁移落地时以 Alembic/等价脚本为准；以下为详设口径。

```sql
CREATE TABLE askdata.eval_template (
  id           BIGSERIAL PRIMARY KEY,
  code         VARCHAR(64)  NOT NULL UNIQUE,
  name         VARCHAR(128) NOT NULL,
  version      VARCHAR(32)  NOT NULL DEFAULT 'v1',
  remark       VARCHAR(512),
  enabled      BOOLEAN      NOT NULL DEFAULT TRUE,
  created_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
  updated_at   TIMESTAMPTZ  NOT NULL DEFAULT now()
);

CREATE TABLE askdata.eval_project (
  id                    BIGSERIAL PRIMARY KEY,
  workspace_id          BIGINT       NOT NULL,
  name                  VARCHAR(128) NOT NULL,
  remark                VARCHAR(512),
  template_id           BIGINT       NOT NULL REFERENCES askdata.eval_template(id),
  source_connection_id  BIGINT       NOT NULL,
  source_database       VARCHAR(128),
  source_schema         VARCHAR(128),
  work_connection_id    BIGINT       NOT NULL,
  work_database         VARCHAR(128),
  work_schema           VARCHAR(128),
  owner_user_id         BIGINT       NOT NULL,
  created_at            TIMESTAMPTZ  NOT NULL DEFAULT now(),
  updated_at            TIMESTAMPTZ  NOT NULL DEFAULT now()
);
CREATE INDEX idx_eval_project_ws ON askdata.eval_project(workspace_id);

CREATE TABLE askdata.eval_case (
  id                 BIGSERIAL PRIMARY KEY,
  case_key           VARCHAR(64)  NOT NULL UNIQUE,
  scope              VARCHAR(32)  NOT NULL,  -- TEMPLATE | PROJECT_CUSTOM
  template_id        BIGINT       REFERENCES askdata.eval_template(id),
  project_id         BIGINT       REFERENCES askdata.eval_project(id),
  category           VARCHAR(64)  NOT NULL,
  govern_subtype     VARCHAR(32),            -- BOARD | HITL_SUPPLEMENT | HITL_NO_SUPPLEMENT
  question           TEXT         NOT NULL,
  expect_sql         TEXT,
  compare_mode       VARCHAR(32)  NOT NULL,
  compare_spec_json  JSONB        NOT NULL DEFAULT '{}',
  hitl_replies_json  JSONB,
  tags_json          JSONB,
  difficulty         SMALLINT,
  enabled            BOOLEAN      NOT NULL DEFAULT TRUE,
  created_at         TIMESTAMPTZ  NOT NULL DEFAULT now(),
  updated_at         TIMESTAMPTZ  NOT NULL DEFAULT now(),
  CONSTRAINT ck_eval_case_scope CHECK (
    (scope = 'TEMPLATE' AND template_id IS NOT NULL AND project_id IS NULL)
    OR (scope = 'PROJECT_CUSTOM' AND project_id IS NOT NULL)
  )
);
CREATE INDEX idx_eval_case_tpl ON askdata.eval_case(template_id);
CREATE INDEX idx_eval_case_proj ON askdata.eval_case(project_id);

CREATE TABLE askdata.eval_task (
  id              BIGSERIAL PRIMARY KEY,
  project_id      BIGINT       NOT NULL REFERENCES askdata.eval_project(id),
  workspace_id    BIGINT       NOT NULL,
  name            VARCHAR(128) NOT NULL,
  status          VARCHAR(32)  NOT NULL DEFAULT 'PENDING',
  metrics_json    JSONB,
  error_message   TEXT,
  created_by      BIGINT       NOT NULL,
  started_at      TIMESTAMPTZ,
  finished_at     TIMESTAMPTZ,
  created_at      TIMESTAMPTZ  NOT NULL DEFAULT now()
);
CREATE INDEX idx_eval_task_ws ON askdata.eval_task(workspace_id, created_at DESC);

CREATE TABLE askdata.eval_task_case (
  id                   BIGSERIAL PRIMARY KEY,
  task_id              BIGINT       NOT NULL REFERENCES askdata.eval_task(id) ON DELETE CASCADE,
  case_id              BIGINT,                  -- 原用例 id，可空（仅追溯）
  case_key             VARCHAR(64)  NOT NULL,
  question             TEXT         NOT NULL,
  expect_sql           TEXT,
  compare_mode         VARCHAR(32)  NOT NULL,
  compare_spec_json    JSONB        NOT NULL DEFAULT '{}',
  govern_subtype       VARCHAR(32),
  hitl_replies_json    JSONB,
  status               VARCHAR(32)  NOT NULL DEFAULT 'PENDING',
  ask_sql              TEXT,
  ask_error            TEXT,
  hitl_rounds          INT          NOT NULL DEFAULT 0,
  compare_score        NUMERIC(8,4),
  compare_detail_json  JSONB,
  expect_row_count     INT,
  ask_row_count        INT,
  trace_id             VARCHAR(64),
  workflow_id          BIGINT,
  run_id               BIGINT,
  started_at           TIMESTAMPTZ,
  finished_at          TIMESTAMPTZ
);
CREATE INDEX idx_eval_task_case_task ON askdata.eval_task_case(task_id, status);
```

## 11. 跑批时序（测评单条）

```text
Front/API          EvalRunner         Generate(eval_mode)    HitlPolicy      WorkflowRunner    sqlwork
    |                  |                      |                  |                 |              |
    | start task       |                      |                  |                 |              |
    |----------------->|                      |                  |                 |              |
    |                  | generate(question)   |                  |                 |              |
    |                  |--------------------->|                  |                 |              |
    |                  |     needs_hitl?      |                  |                 |              |
    |                  |---------------------------------------->|                 |              |
    |                  |  reply or refuse     |                  |                 |              |
    |                  |<----------------------------------------|                 |              |
    |                  | (loop generate)      |                  |                 |              |
    |                  | auto_save draft      |                  |                 |              |
    |                  | execute workflow     |                  |                 |              |
    |                  |--------------------------------------------------------->|              |
    |                  |                      |                  |                 |------------->|
    |                  | expect_sql exec (read-only)             |                 |              |
    |                  |---------------------------------------------------------------------->|
    |                  | comparer → persist eval_task_case       |                 |              |
```
