# 详细设计：前端与界面设计（横向）

> **横向详细设计**（跨模块 UI）。  
> **顶栏顺序（已定）**：首页 → SQL 工作台 → **权限管控** → 资产管理 → 用户中心 → 系统管理。  
> 业务规则以 [../需求/01-需求设计.md](../需求/01-需求设计.md) 为准；可点原型见 [../../ui/](../../ui/)。  

---

## 1. 设计原则

- 浅色中后台；主色 Ant Design 蓝 `#1677FF`；背景 `#F5F5F5`。
- 顶栏 / 内容白底；正文 14px；删除二次确认；表单错误贴字段。
- **公司域 / 个人域**靠上下文切换区分，**不**并列「我的实例 / 我的连接 / 我的工作空间」菜单（避免重复）。

---

## 2. 信息架构与顶栏

| 一级（顺序） | 侧栏二级（公司域） | 侧栏二级（个人域） | 谁可见 |
| --- | --- | --- | --- |
| **首页** | — | — | 登录用户（内容三套见 §8） |
| **SQL 工作台** | 无侧栏 | 无侧栏 | `sqlwork.*` |
| **权限管控** | 全局管控、工作空间授权 | **仅**工作空间授权（个人） | 公司：`auth.*`；个人：进入个人域后 |
| **资产管理** | 实例、连接 | 实例（个人）、连接（个人） | 公司：instance/connection view；个人：进入个人域后 |
| **用户中心** | 用户 / 部门 / 角色 / 权限 | 建议隐藏 | 功能权限（公司域） |
| **系统管理** | 应用管理 | 建议隐藏 | 超管（公司域） |

顶栏一级横排，点击一级直达模块默认页。  
右上角：**仅用户名**（不显示角色）→ 下拉含「个人空间」；另保留退出登录。

### 2.1 公司域 vs 个人域（已定：A + 视觉补强）

| | 公司域（默认） | 个人域 |
| --- | --- | --- |
| 进入 | 登录默认；或点「退出个人空间」 | 用户菜单「个人空间」→ 个人空间首页 →「进入」 |
| 域提示 | 无 | 顶栏徽章「当前：个人空间」 |
| 退出 | — | **明显出口**：顶栏「退出个人空间」按钮（用户菜单可再放一项） |
| 侧栏 | 原菜单文案 | **同一路由**，文案加「（个人）」前缀 |
| 数据 | 公司资产 / 公司工作空间 | 个人资产 / 本人个人工作空间 |

## 4. 路由总表

```
/login
/home                               # 三套首页；个人域下为个人空间首页

/sqlwork                            # 选空间（含被授权的他人个人空间）
/sqlwork/workspace/:id

/manage/auth/global-policies        # 仅公司域
/manage/auth/workspaces
/manage/auth/workspaces/:id

/manage/instances
/manage/connections

/user-center/users|depts|roles|permissions
/system/apps
```

列表类 API 请求携带域上下文（如 Header `X-Dbc-Domain: COMPANY|PERSONAL` 或 query），服务端强制隔离。

---

## 5. 用户中心

既有能力不变；权限树含 `usercenter.personal.space.view`；种子角色含 `DATA_OPERATOR`。

---

## 6. 权限管控

### 6.1 全局管控

仅**公司域**菜单。策略作用范围仅公司工作空间。

### 6.2 工作空间授权

公司域：公司工作空间（创建仍要 `DB_ADMIN`）。  
个人域：仅本人个人工作空间；自助创建（不要求 `DB_ADMIN`）。

---

## 7. 资产管理

公司域：部门 data-scope。  
个人域：仅所有者个人实例/连接；创建时写入个人归属。

---

## 8. 首页（三套）

| 场景 | 内容 |
| --- | --- |
| 非 `DATA_OPERATOR` 默认 | 产品快速上手 + SQL 执行业务流程 |
| `DATA_OPERATOR` 默认 | 工作台引导 + 个人空间说明 |
| 个人空间首页（全员同一套） | 未创建→创建；已创建→进入；使用说明 |

---

## 9. SQL 工作台

选空间列表：本人加入的公司空间 + 本人个人空间 + **被授权的他人个人空间**。  
被授权人**只能**由此进入他人个人空间执行，不能进对方个人域改配置。

编辑页：多会话 Tab；下方面板「执行日志 | 结果」；无权限日志须展示对象与缺失操作。

---

## 10. 权限与按钮显隐（摘要）

| 可见性 | 条件 |
| --- | --- |
| 个人空间菜单 | `usercenter.personal.space.view` |
| 退出个人空间 | 当前个人域 |
| 全局管控 | 公司域 + `auth.global.policy.view` |
| 资产管理（公司） | instance/connection view |
| 资产管理（个人） | 已进入个人域 |
| SQL 工作台 | `sqlwork.*` |

---

## 11. 前端状态

建议 Pinia：`domain: 'COMPANY' | 'PERSONAL'`；进入/退出时刷新菜单文案与列表请求域参数；退出时清理个人域选中态。
