问题（快照）

帮我看下「活跃」客户上季度贡献

HITL 补充（写死）

第 1 轮：活跃=状态为 active 且上季度有已签约订单的客户

期望 SQL

SELECT c.customer_code, SUM(o.total_amount) AS amt
FROM company.crm_customer c
JOIN company.sal_sales_order o ON o.customer_id = c.id
WHERE c.status = 'active'
  AND o.status IN ('signed','delivering','closed')
  AND o.sign_date >= DATE '2025-07-01'
  AND o.sign_date < DATE '2025-10-01'
GROUP BY c.customer_code
ORDER BY c.customer_code;

问数 SQL

SELECT c.customer_code, SUM(o.total_amount) AS contrib
FROM company.crm_customer c
INNER JOIN company.sal_sales_order o ON o.customer_id = c.id
WHERE c.status = 'active'
  AND o.sign_date BETWEEN '2025-07-01' AND '2025-09-30'
  AND o.status <> 'cancelled'
GROUP BY c.customer_code;

比对摘要

键集合一致；金额容差内全部匹配。列名 contrib↔amt 已按 compare_spec 映射。
