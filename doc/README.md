## 要点

- 服务名 = 目录名 = URL 前缀（如 `dbc-usercenter`）
- Java 包名：`com.lyj.dbc.{服务短名}.{功能模块}`
- 前端：`src/common/` + `src/modules/{域}/`
- 目标库访问只经 `dbc-sqlwork`；manage 不直连目标库
- 内置角色：超级管理员、系统管理员、数据库管理员（无平台「数据操作人员」）
- `admin` = 超级管理员
